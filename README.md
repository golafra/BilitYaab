# ✈️ بلیط‌یاب (BilitYaab)

سامانه پایش و هشدار ظرفیت بلیط پرواز با اطلاع‌رسانی در پیام‌رسان بله.

به راهنمای اجرای محلی (Local) پروژه خوش آمدید. این سند به شما کمک می‌کند پروژه را به راحتی روی سیستم ویندوز خود اجرا کرده، تغییرات دلخواهتان را اعمال کنید و آن را با گیت‌هاب همگام‌سازی نمایید.

---

## 🚀 روش اجرای سریع و آسان در ویندوز (یک کلیک)

ما یک فایل راه‌انداز خودکار برای کاربران ویندوز طراحی کرده‌ایم تا بدون نیاز به نوشتن دستورات پیچیده، تمام مراحل نصب و اجرا را با یک کلیک انجام دهند:

1. فایل **`run-windows.bat`** را در پوشه اصلی پروژه پیدا کرده و روی آن دو بار کلیک کنید.
2. اسکریپت به طور خودکار موارد زیر را انجام می‌دهد:
   - بررسی نصب بودن **Node.js** بر روی سیستم شما.
   - ایجاد فایل تنظیمات شخصی **`.env`** در صورت عدم وجود.
   - نصب خودکار تمام پکیج‌ها و پیش‌نیازهای پروژه (`npm install`).
3. در پایان از شما پرسیده می‌شود که می‌خواهید برنامه در چه حالتی اجرا شود:
   - **گزینه 1 (پیش‌فرض):** حالت توسعه (Development Mode) - مناسب برای ادیت و اعمال تغییرات لحظه‌ای.
   - **گزینه 2:** حالت تولید (Production Mode) - مناسب برای اجرای نهایی، سریع و بهینه.
4. پس از اتمام، مرورگر خود را باز کرده و به آدرس زیر بروید:
   **[http://localhost:3000](http://localhost:3000)**

---

## 🛠️ روش راه‌اندازی دستی (مرحله به مرحله)

اگر ترجیح می‌دهید دستورات را به صورت دستی در Terminal (مانند PowerShell، Git Bash یا Command Prompt) وارد کنید، مراحل زیر را دنبال نمایید:

### ۱. نصب پیش‌نیازها
مطمئن شوید که **Node.js** (نسخه ۱۸ به بالا) روی سیستم شما نصب است. برای بررسی، دستور زیر را در ترمینال بزنید:
```bash
node -v
```

### ۲. نصب بسته‌های نرم‌افزاری
ترمینال را در پوشه اصلی پروژه باز کرده و دستور زیر را برای نصب وابستگی‌ها بنویسید:
```bash
npm install
```

### ۳. تنظیم متغیرهای محیطی (Environment Variables)
یک فایل به نام `.env` در پوشه اصلی پروژه بسازید (یا فایل `.env.example` را کپی کرده و نام آن را به `.env` تغییر دهید). سپس کلیدهای خود را در آن وارد کنید:
```env
GEMINI_API_KEY="کلید_جمینای_شما"
APP_URL="http://localhost:3000"
```
*نکته: فایل `.env` در لیست نادیده‌گرفته‌های گیت (`.gitignore`) قرار دارد، بنابراین اطلاعات شخصی و کلیدهای شما به گیت‌هاب ارسال نخواهند شد و کاملاً امن خواهند بود.*

### ۴. اجرای برنامه
* **حالت توسعه (توصیه شده برای تست و تغییر کُد):**
  ```bash
  npm run dev
  ```
* **حالت تولید (سریع‌ترین حالت اجرا):**
  ```bash
  npm run build
  npm start
  ```

سپس آدرس **`http://localhost:3000`** را در مرورگر خود باز کنید.

## 🔄 نحوه ارسال و همگام‌سازی کدهای پروژه با گیت‌هاب (GitHub)

از آنجا که پروژه شما به گیت‌هاب متصل شده است، برای ارسال تغییرات جدید به مخزن (Repository) خود در گیت‌هاب، مراحل زیر را در پوشه پروژه انجام دهید:

### ۱. بررسی وضعیت فایل‌های تغییر یافته:
```bash
git status
```

### ۲. اضافه کردن فایل‌ها به صف ارسال:
```bash
git add .
```

### ۳. ثبت تغییرات با یک پیام مناسب:
```bash
git commit -m "feat: اضافه شدن موتور کراولر هوشمند مجهز به مرورگر بدون سرپرست برای پایش دقیق صندلی ها"
```

### ۴. ارسال کُدها به شعبه اصلی گیت‌هاب (Push):
```bash
git push origin main
```
*(اگر نام شاخه اصلی شما چیز دیگری مانند master است، آن را جایگزین main کنید).*

## ⚡ موتور کراولر هوشمند تحت مرورگر (Browser-based Scraping)
در به‌روزرسانی اخیر، سیستم مانیتورینگ به پکیج قدرتمند **Puppeteer (Chromium)** مجهز شده است. 
* **چرا این تغییر مهم است؟** بسیاری از سایت‌های هواپیمایی (مانند سپهران) به صورت تک‌صفحه‌ای (SPA) و با استفاده از React/Next.js پیاده‌سازی شده‌اند. بنابراین اطلاعات پروازها به صورت دینامیک و پس از لود شدن کامل اسکریپت‌ها رندر می‌شود. کراولر معمولی (به دلیل عدم اجرای جاوااسکریپت) این پروازها را خالی یا ناقص می‌دید. اما اکنون یک مرورگر واقعی در پس‌زمینه باز شده، چند ثانیه صبر می‌کند تا رندر کامل انجام شود و سپس پروازها را با دقت ۱۰۰٪ استخراج می‌کند!
* **نکته بسیار مهم در اجرا:** اگر از قبل پوشه `node_modules` را روی سیستم خود داشتید، حتماً دستور `npm install` را یکبار دیگر اجرا کنید تا پکیج Puppeteer مرورگر اختصاصی Chromium سازگار با ویندوز شما را به صورت خودکار دانلود کند.

## 💡 نکات کلیدی برای پایش بی‌وقفه در ویندوز
* **عدم خواب رفتن سیستم (Sleep):** برای پایش مداوم پروازها، مطمئن شوید تنظیمات Sleep کامپیوتر خود را روی حالت "Never" قرار داده‌اید تا سیستم در طول پایش خاموش نشود.
* **کلید جمینای:** اگر می‌خواهید از سیستم تحلیل هوشمند استفاده کنید، دریافت رایگان کلید API از پنل Google AI Studio و ذخیره آن در فایل `.env` ضروری است.
